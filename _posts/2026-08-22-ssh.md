When you create a public/private key pair, the public key is tied to your user account in all servers you need to access. The private key is stored locally on your machine (i.e., SSH client).


## Steps to establish ssh connection with server
1. Initiate ssh connection, server sees your username
2. Server looks up username and the corresponding public key
3. Server randomly generates challenge -> send to SSH client
4. SSH client uses private key to create a digital signature
5. Send signature back to server, which verifies with public key


## Instructions for creating + adding SSH key:
- Create: `ssh-keygen -t ed25519 -C "email@site.com"`
    - Generates public and private keys automatically in `~/.ssh`
- Load private key to agent memory (if ssh key has a password):
    - `eval "$(ssh-agent -s)"`
    - `ssh-add ~/.ssh/id_ed25519`
- Add public key to website you're trying to access (e.g., gitlab): `cat ~/.ssh/id_ed25519.pub`

## Example use case: running code in HPC
- Create local key + add local public key to website (e.g., gitlab)
- Create key in cluster + add cluster's public key to website
- Can push/pull to the same gitlab repo, thus syncing local and cluster
